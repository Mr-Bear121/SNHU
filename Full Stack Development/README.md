
Architecture

The project employs a combitantion of frontend approaches including handlebars: this is used for templating JSON data and rendering Dynamic content to the customer facing side of the application. This is a lightweight templating engine that symplifies the integration process of dynamic data into staic pages. this offers flexibility for straightforward interactions.

javaScript and Typescript: this provides interactivity and dynamic updates to the html conten.

Single Page Application (SPA): the admin side uses Angular to create a SPA. this allows for a smooth and dynmic user experience with faster load times and no full page reloads. This is ideal for administrator tasks.

The Backend and database uses Node.js with Express.js to handle API requests and responses. a NoSQL MongoDB was chosen for its flexability and scalability. Mongos Database schema-less design allows for easy modification to the data model without disrupting the application.

Functionality

JSON differs from JavaScript in that it is a lightweight data-interchange fromat used for structuring data. unlike JavaScript, which includes functions and logic, JSON is strictly for data representation. This project uses JSON as a bridge between the front-end and back-end. This Allows for seamless communication between the two.
